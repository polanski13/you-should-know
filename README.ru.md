# You Should Know

**Независимый взгляд на работу твоего coding-агента.**

[English](README.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md)

[![CI](https://github.com/polanski13/you-should-know/actions/workflows/ci.yml/badge.svg)](https://github.com/polanski13/you-should-know/actions/workflows/ci.yml)
[![MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Агент может выполнить задачу, но не объяснить важное последствие своего решения. You Should Know в фоне читает диалог и показывает короткую заметку с подтверждением из переписки, если это может повлиять на твой выбор.

> **Обрати внимание** · Кеширование повышает стоимость для пользователей, которые задают только один вопрос.
>
> Первый запрос стоит на 25% дороже, а большинство пользователей пока не задают уточняющих вопросов. Это может помешать уложиться в бюджет $100 в месяц. Перед включением кеширования для всех стоит проверить, как часто люди продолжают диалог.
>
> **На основании:** «Первый запрос стоит на 25% дороже»

_Иллюстративный пример. Большинство проверок должны обходиться без заметки._

## Возможности

- Замечает существенные компромиссы, скрытые расходы, расхождения с целью и неподтверждённые заявления об успехе.
- Сохраняет заметку только при наличии подтверждающих цитат из диалога.
- Помнит уже понятные тебе темы отдельно для каждого проекта.
- Работает независимо от основного агента, без инструментов модели и автоматического изменения файлов.
- Ограничивает частоту и число запросов; реже вмешивается, если заметки игнорируют.
- Поддерживает английский, русский, китайский и автоматический выбор языка по последнему сообщению.

**Фоновые проверки расходуют лимиты модели, даже когда заметка не появляется.** У проекта нет отдельного сервиса или подписки.

## Интеграции

| Клиент                 | Наблюдение                                                       | Где появляются заметки                                    |
| ---------------------- | ---------------------------------------------------------------- | --------------------------------------------------------- |
| **OpenCode 2.2.x**     | Нативный серверный плагин; текущая модель и существующий аккаунт | Карточка над вводом в Desktop; уведомление и `/ysk` в TUI |
| **Codex 0.162.0+**     | Асинхронные хуки; по умолчанию — авторизованный app-server Codex | При следующем сообщении или сразу через `ysk watch`       |
| **Claude Code**        | Асинхронные командные хуки; настроенный провайдер наблюдателя    | При следующем сообщении или через `ysk watch`             |
| **Другие MCP-клиенты** | Явный вызов `ysk_observe` через stdio                            | Ответ инструмента и сохранённые заметки                   |

API расширений Desktop в OpenCode экспериментальный. MCP-клиент должен сам передать контекст и вызвать проверку. Хуки Claude Code не используют подписку Claude: для наблюдателя нужен авторизованный Codex или API-провайдер.

## Установка из исходников

Проект пока распространяется через этот репозиторий. Для установки не нужен опубликованный npm-пакет.

Требуются Node.js **22.18+**, npm и Git.

```sh
git clone https://github.com/polanski13/you-should-know.git
cd you-should-know
npm ci
npm run build
npm link
```

Не перемещай checkout после установки: плагин и хуки используют его путь. После обновления исходников снова выполни `npm ci && npm run build`.

### OpenCode

Добавь **абсолютный путь к каталогу репозитория** в глобальный `~/.config/opencode/opencode.json` или `.jsonc`, сохранив существующие элементы `plugins`:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    {
      "package": "/absolute/path/to/you-should-know",
      "options": { "language": "auto" },
    },
  ],
}
```

Одна запись подключает серверную, терминальную и Desktop-части. Для Desktop нужна глобальная запись; конфигурация проекта подключает серверную и TUI-части. OpenCode применяет изменения автоматически.

Продолжай работать как обычно. Если проверка найдёт важное, появится заметка. Раскрой её, чтобы увидеть объяснение и цитаты. Кнопки **Понятно** и **Я это знаю** запоминают тему. **Обсудить в чате** вставляет заметку в поле ввода Desktop — отправку контролируешь ты. В TUI выбор обсуждения отправляет явное уточняющее сообщение.

### Codex

```sh
codex login
ysk init
ysk doctor
ysk install codex
codex --enable hooks
```

Установщик дополняет `hooks.json`, сохраняет остальные хуки и создаёт резервную копию исходного файла. Фоновые проверки не задерживают инструменты. Хук `UserPromptSubmit` показывает ожидающую заметку при следующем сообщении.

Для немедленного просмотра запусти во втором терминале **из каталога рабочего проекта**:

```sh
ysk watch
```

### Claude Code

Нужна версия Claude Code с поддержкой асинхронных командных хуков. Сначала настрой провайдер через `ysk init` и проверь его командой `ysk doctor`, затем:

```sh
ysk install claude-code
```

По умолчанию используется авторизация Codex CLI. Можно выбрать OpenAI-совместимый API или Anthropic API — см. [руководство](docs/ru/guide.md#провайдеры).

### MCP

Добавь stdio-сервер в настройки клиента. Пример использует распространённый формат `mcpServers`; внешняя структура зависит от клиента:

```json
{
  "mcpServers": {
    "you-should-know": {
      "command": "node",
      "args": [
        "/absolute/path/to/you-should-know/dist/cli.js",
        "mcp",
        "--cwd",
        "/absolute/path/to/project"
      ]
    }
  }
}
```

Инструменты: `ysk_observe`, `ysk_notes`, `ysk_feedback`. Ресурс заметок: `ysk://notes`. Обратная связь должна отражать явный ответ человека.

## Повседневные команды

Запускай из каталога проекта или добавляй `--cwd /path/to/project`:

```sh
ysk notes
ysk show <note-id>
ysk feedback <note-id> known
ysk pause
ysk resume
ysk watch
```

Удалить хуки: `ysk uninstall codex` или `ysk uninstall claude-code`. Для отключения OpenCode удали запись плагина. Заметки и сторонние настройки сохраняются.

## Значения по умолчанию

| Параметр               | Значение                                                                                            |
| ---------------------- | --------------------------------------------------------------------------------------------------- |
| Частота                | Каждые 6 шагов модели в OpenCode; каждые 6 событий с результатами инструментов в транскриптах хуков |
| Пауза между проверками | 120 секунд в рамках сессии                                                                          |
| Бюджет запросов        | 20 на сессию; 8 в час на проект                                                                     |
| Таймаут                | 45 секунд                                                                                           |
| Текст диалога          | До 40 000 символов; 6 000 на сообщение                                                              |
| Заметки                | Не более одной за ход; до 100 на проект                                                             |
| Хранение               | 30 дней, очистка при обращении                                                                      |

[Настройки](docs/ru/guide.md#настройки) позволяют изменить эти значения. Ручная проверка пропускает ограничения частоты и задержки, но учитывает бюджет, паузу и повторы.

## Данные и ограничения

Ограниченный фрагмент диалога отправляется выбранному провайдеру. OpenCode использует собственный stateless API генерации текста. Codex — временный read-only поток с отключёнными инструментами, MCP, плагинами и хуками. HTTP-провайдеры получают только текстовые запросы.

Распространённые форматы секретов скрываются перед запросом. **Это дополнительная защита, а не гарантия удаления всех секретов.** Заметки содержат короткие цитаты и хранятся локально в отдельных файлах проектов с ограниченными правами. У проекта нет телеметрии и центрального сервера заметок. Политики хранения и оплаты выбранного провайдера продолжают действовать.

Проверка цитаты подтверждает её наличие, но не правильность вывода модели. Подсказки помогают принимать решения. Подробнее о хранении, отмене и диагностике — в [руководстве](docs/ru/guide.md).
